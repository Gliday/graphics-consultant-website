# Site Structure — Loose Grid

## Pages

1. **Home** (`/`) — hero (typographic opening + halftone portrait), selected work grid (6–8 featured), services strip, client logofolio, CTA.
2. **Selected Work** (`/work`) — full project grid with category filters (Branding, Campaign/Art Direction, UX/UI, Posters & Print).
3. **Case study** (`/work/[slug]`) — one per project (see field mapping below). Next/previous project nav + contact CTA.
4. **Services** (`/services`) — service tiles (Branding & Identity, Art Direction & Campaigns, UX/UI Design, Graphic Design & Print) + process overview + "Request a Quote" CTA.
5. **About** (`/about`) — bio, experience timeline, tools, logofolio (or link to it), "available for work" status.
6. **Contact / Request a Quote** (`/contact`) — enquiry form (name, email, project type, budget range optional, message), direct email/phone, socials.
7. **404** — on-brand custom not-found page with loose-grid motif and a way back to Home/Work.

No standalone "Rate Card" page — folded into Services as a quote-request flow per confirmed direction.

## Case study field mapping (per project, only populate fields with real data)

- title, client, year, discipline/category, tools
- summary (1–2 lines for grid cards)
- challenge / brief
- approach
- deliverables
- image gallery (curated, optimized)
- outcome/results (only where the PDF stated them — NCBA, Tusker campaigns)
- external project link (only if client confirms OK to link out)
- next/previous project
